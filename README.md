# Pet Friendly App

This is a simple Node.js application that lets users view pet friendly places and add new ones. Users can also comment on places and upload photos.

## Features
* View all pet friendly places
* Add a new place with a name and description
* Comment on a place
* Upload photos for a place (stored as base64 strings)

## Running

No external dependencies are required. To start the server run:

```bash
node server.js
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.
